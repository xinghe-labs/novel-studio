# 新书开机预检(建书完成度清单)

在互动建书的确认单定稿之前、以及第一章合同之前读取本文件。目的不是多问问题,而是让每个未决项都有归属:可后定的进入确认单"仍未决定"并标注**不阻塞**;写前必须定的,清零才开机。分析瘫痪与过早开写是同一种病的两面——95% 闸门防后者,本清单防前者。

使用方式:确认单定稿前,按 A-E 逐阶段与作者过一遍,每项看"完成判据"而不是凭感觉;F 是第一章合同之前的最后一关,有一项不过就不生成第一章合同。旧项目补建(风格合同五段、声音锚点、黑名单)按项目写入规则走,不回填历史章节。

## A. 方向与研究(需求层闸门的实体)

| 事项 | 完成判据 |
|---|---|
| 平台核验 | 目标平台的当日官方规则(字数、签约、内容边界)已登记为来源,带观察日期;不凭记忆或旧快照 |
| 市场研究 | 6-9 个候选按"目标平台近期/其他平台或出版/跨媒介公版"三层配齐;获批候选完成机制拆解——读者承诺×冲突发动机×关系压力×信息机制×原创变量,五格逐一有内容 |
| 方向选择 | 3 个原创方向各有承诺、代价、可持续冲突的对比;推荐项说明依据来自用户哪些偏好 |
| 原创边界 | `research/originality-plan.json` 每个结构维度写了**改变因果的改造**(只改人名、时代、职业不算);对标作品中不带入本书的高频套路,进入黑名单种子 |
| 立项时机 | 平台确认与商业前提(签约、结算、同期单书)已落地;立项不建立在未核验的假设上 |
| 失败同行预验尸 | 同题材 3-5 本失败同行(有体量但数据断崖)各记录一句死因;Agent 从编辑立场给出至少三条"这本书会死"的反证,作者逐条回应——回应不了的进入确认单作为写前必须修项 |
| 更新承诺与存稿缓冲 | 日更字数×每周天数、开更前缓冲章数、断更预案(缓冲烧穿时的降级方案)三项已由作者填写;不填不立项 |
| 平台义务核查 | 已有签约作品的独家条款范围(按作品/按人/按期间)已核查,确认不波及新书;有疑问先报告证据再立项 |

## B. 故事核心与人物(故事层闸门的实体)

- **核心四件套**:欲望 + 阻力 + 代价 + 信念转变,一句话可复述;**读者承诺**单独成句(读者持续翻页为了什么体验)。
- **主题写成问题**,不写成作者宣布的答案。
- **人物档案**:每个主要人物有外在欲望、内在需要、核心恐惧、会付出代价的缺陷、可观察的声音标记(词汇、句长、幽默方式);反派按**对抗力量阶梯**(即时/章节/卷级/幕后)有名有因果,不止"制造关卡"。
- **知识边界预规划**:核心秘密逐条分好谁知道、谁相信、谁声称、读者知道什么——这一步做完,后续每章的知识边界审计才有基准。

## C. 声音与风格(voice 阶段)

- 风格合同五段齐全:POV 与叙述距离 / 时态、语气与节奏 / 人物声音与避免项 / **每章字数带与断章风格** / **禁用措辞与套话黑名单**(A 阶段种子落进这里)。
- **声音锚点**:`story-bible/voice-anchor.md` 就位——每个 POV 两三段作者亲写或作者指定的代表片段,注明出处;不得用模型生成文本冒充。
- **内容边界**:平台尺度与作者尺度分开记录,以当日核验的平台规则为准。

## D. 结构与大纲

- **全书层**:起始失衡、主要升级、不可逆转折、高潮选择、结局余波;每个转折标注它废掉哪些期待线、开出哪些新线——转折不许是孤岛。
- **期待线表**:每条主线标四列——类型(目标逼近/威胁逼近/谜面展开/关系牵引)、首次铺设章、中间安慰点(每 2-3 章一次部分兑现或加码)、预计兑现窗口。判据:每条主线都能指出铺设章;指不出的是"用'然后'连接的事件排列"。
- **黄金三章合同草案进确认单**:每章三行(进入/兑现/卡点),三章钩子不同型,书名-简介-首章承诺互相对齐。
- **章节层只细到前 3-5 章**,卷层写完第一卷;**中段预案**预留第一个假高潮或中期目标置换的位置(防 30 章后塌陷)。
- **逾期线索清查**:回收窗口早于当前章、且未回收未废弃的线索逐条裁决——兑现、再铺设、改窗口或废弃;逾期的期待按线索处理,不许悬着。

## E. 形式与工程

- framework-sync 九输入齐备、非空、无"待确认"占位符;`project-settings.json` 只含 POV/时态/目标篇幅。
- 风格合同五段在手;书名-简介-首章一致性核对过(书名可暂定,则记录改名触发点)。
- 作品入口类型(连载/短故事)与语义 slug 定死;research 来源全部登记哈希与权利,`originality_compare` 标记到位。

## F. 开机检查单(第一章合同之前)

1. 需求层与故事层信心均 ≥95,且能由会话文件的"已确认/已委托/阻断项"复核,不是没有依据的百分比。
2. `framework-sync` 完成,`stage: complete` 与 `confirmation: confirmed` 成对。
3. 风格合同五段齐全,voice-anchor 就位。
4. 期待线表每条主线有铺设章;对手表四层有名有因果。
5. 黄金三章草案齐,三章钩子不同型;黑名单不少于 10 条。
6. 原创计划每个结构维度有因果改造;世界硬规则每条有成本、控制者与例外归属。
7. 平台规则当日核验记录在手。
8. 确认单"仍未决定"已分两类:**可后定**(书名、配角、远期细节)与**写前必须定**(世界硬规则、POV、声音)——后者为零,才生成第一章合同。
9. 线索账本无逾期回收窗口——有逾期的,已按 D 段逐条裁决并记录进确认单或作者决策。
